# 💰 Expense Tracker System

A simple Expense Tracker project made using Python, Pandas, and NumPy.

This program helps users:
- Add daily expenses
- View all expenses
- Search expenses
- Delete expenses
- View spending statistics
- Analyze spending by category

All data is stored permanently in a CSV file.

---

# 📌 Features

✅ Add Expenses  
✅ View All Expenses  
✅ Search Expenses  
✅ Delete Expenses  
✅ Category-wise Spending Summary  
✅ Highest & Lowest Expense Detection  
✅ Spending Statistics using NumPy  
✅ CSV File Storage using Pandas
